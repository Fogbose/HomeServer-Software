# Contributor instructions

Keep this software repository independent of host paths, VPN identities and
private deployments. Never copy private state, credentials, browser profiles or
diagnostics. Preserve upstream licensing. Test with synthetic accounts only.
Infrastructure belongs to the HomeServer sibling; no host firewall or Docker
socket access from the Maison app. Run Python tests, PHP controller tests and
language syntax checks before proposing a change. Do not claim these replace
real-device synchronization, notifications or calls.
