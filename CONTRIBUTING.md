# Contributing

Explain the user problem, resulting behavior and validation in focused pull
requests. Use synthetic data. Run the commands in the README; PHP 8.3+ and Python
3.10+ are required for the tests, Node.js for JavaScript syntax checking. Test UI
changes in a separate Nextcloud instance with a non-admin account and a narrow
mobile viewport. No live personal server is used by CI.

Keep contributions under MIT; do not vendor upstream apps or their logos.
Support is best effort, with no response-time commitment. Discuss behavior
respectfully and never post credentials or personal screenshots in issues.
